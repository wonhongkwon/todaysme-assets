# todaysme-assets

블로그 [**Let's get started**](https://letsgetstartedbydavid.blogspot.com/)에 쓰이는 이미지 에셋 저장소입니다.
글마다 표지(cover)와 본문 삽화(body) 이미지를 직접 만들어 이 저장소에 두고, 블로그 본문에서 raw URL로 불러 씁니다.

- 블로그: <https://letsgetstartedbydavid.blogspot.com/>
- 다루는 주제: 경제·가상자산 규제, 여행 일정, 문화·공연, 개인 개발 기록
- 이미지 규격: 표지는 OG 대응(1200x630), 본문 삽화는 글 성격에 따라 가변

## 디렉토리 구조

```
economy/      경제·가상자산 편 이미지
travel/       여행 편 이미지
performance/  공연·전시 편 이미지
vibe-coding/  개발 기록 편 이미지
```

각 하위 디렉토리는 글 슬러그 이름을 쓰고, 그 안에 `cover.png`와 `body.png`가 들어갑니다.
예를 들어 `economy/crypto-transfer-rules-split/cover.png`는
[코인 해외 이전 규제 편](https://letsgetstartedbydavid.blogspot.com/2026/08/korea-crypto-transfer-rules-split-2026.html)의 표지입니다.

## 이미지 사용 방법

```html
<img src="https://raw.githubusercontent.com/wonhongkwon/todaysme-assets/main/economy/<슬러그>/cover.png">
```
